# refactorer

Do not edit this file. It is the shared answer template. Print this block, with your own values, at the end of your turn.

The final message of the refactorer. The cleanup is in the tree. Report references, not content: give the file path and the line number.

```
SUBSYSTEM: <subsystem>
STATUS: done | blocked | needs-input
NEXT: operator
VERIFY: <the swarm.gate command, then CRAP and DRY> => exit <n>
FILES: <path:line ...>
DIAGRAM: <design/subsystems/<subsystem>/model.html, or "none" when the task has no model>
ASSUMPTIONS: <path:line, or "none">
ASK: <only when STATUS is not done>
```

Good: `STATUS: done`, `NEXT: operator`, `VERIFY: ... => exit 0`, `FILES: src/cart.py:41, tests/unit/test_cart.py:12`, `DIAGRAM: design/retention/model.html`, `ASSUMPTIONS: none`.
Bad: `STATUS: done` with no `VERIFY`, or the CRAP table repeated in the message.

Write the prose fields in ASD-STE100 Simplified Technical English. Keep the field names and the tokens exact.
`NEXT` is `operator` when the terminal gate passes: the run ends and the orchestrator relays the verdict. On a failing gate, `STATUS` is not done and `ASK` names the failure.

`DIAGRAM` is the refreshed live view (`sync_python.py` + `render.py` over `design/subsystems/<subsystem>/model.json`). Use `none` when the task has no model.
