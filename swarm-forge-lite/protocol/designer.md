# designer - design answer

Do not edit this file. It is the shared answer template. Print this block, with your own values, at the end of your turn.

The final message of the designer. It designs one module: contracts, wiring, the
test map, and the module skeleton. The forms live in the work files. Report
references, not content: give the file path and the line number.

```
SUBSYSTEM: <subsystem>
ROLE: designer
MODULE: <module id>
STATE: settled | open | blocked
WORK: design/subsystems/<subsystem>/modules/<module>/
SKELETON: design/subsystems/<subsystem>/modules/<module>/SKELETON.md
INTERFACES: design/subsystems/<subsystem>/interfaces/<module>.md
STOP TEST: pass | fail
DECISIONS: <n>
  D1 [<named rule: CQS split, public-shape split, OCP seam, business contradiction>] <path:line> - <one-line question> | options: <a> | <b> | <c> | answer: <operator's>
CONFLICT: <interface path> - <the change needed> - <why>    (or "none")
FOR OTHER ROLES: <path:line - route to <role>, or "none">
OPEN RISKS: <design defaults and assumptions, or "none">
NEXT: critic
```

Good: `STATE: settled`, a `DECISION` that names the CQS or contradiction rule and
the file line, `CONFLICT: none`, `STOP TEST: pass`, `NEXT: critic`.

Bad: the contracts pasted into the message, a method tagged both Command and
Query, or an edit to a frozen interface file.

`STATE: settled` means that the operator resolved every public-shape `DECISION`,
the module stop test passes, and the module honors every frozen interface. **A new
DECISION makes `settled` illegal: return `STATE: open`.** Keep each `DECISION` to
one line.

**A frozen interface that cannot be honored is `STATE: blocked` with `CONFLICT`.**
Do not edit the frozen zone. The orchestrator routes the CONFLICT to the
architect. The architect amends, rejects, or reassigns. Then you continue.

The accepted module is in `design/subsystems/<subsystem>/modules/<module>/`. Give its
path and lines. Do not paste it. `NEXT` is `critic`.
