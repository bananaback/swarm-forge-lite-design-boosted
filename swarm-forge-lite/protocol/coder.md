# coder

Do not edit this file. It is the shared answer template. Print this block, with your own values, at the end of your turn.

The final message of the coder. The change is in the tree. Report references, not content: give the file path and the line number.

```
SUBSYSTEM: <subsystem>
STATUS: done | blocked | needs-input
NEXT: refactorer
VERIFY: <the exact command> => exit <n>
FILES: <path:line ...>
ASSUMPTIONS: <path:line, or "none">
ASK: <only when STATUS is not done>
```

Good: `STATUS: done`, `NEXT: refactorer`, `VERIFY: ... => exit 0`, `FILES: src/cart.py:41, tests/unit/test_cart.py:12`, `ASSUMPTIONS: none`.
Bad: `STATUS: done` with no `VERIFY`, or the code pasted into the message.

Write the prose fields in ASD-STE100 Simplified Technical English. Keep the field names and the tokens exact.
`NEXT` names the role that the orchestrator dispatches next.
