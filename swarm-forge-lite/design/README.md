# design/

Durable, operator-owned design state. The unit is the **subsystem**. One living
record per subsystem, edited in place. No revision, status, or change log.

## Flat record (new subsystems)

```
design/subsystems/<subsystem>/
  GOAL.md            orchestrator scratchpad, max ~40 lines
  requirements.md    frame, goal, Rn/ACn, Cn, Xn, traceability, DECISIONs
  architecture.md    module map, shared files, frozen interface sections
  modules/<m>.md     contract + design + decisions, one file per module
  SKELETON.md        generated by swarm.genRecord
  model.json         topology, edited through swarm.uml
  model.html         derived review page
  review.md          optional critic review
```

The shipped outputs are the spec document (`<SPECS>/NN-<subsystem>.md`), the
features, the tests, the source, and `model.html` for review. Everything else is
working state. Keep it short.

`model.html` is generated. Agents never read it and never edit it. Agents query
`model.json` through `swarm.uml` and render with `swarm.uml({op:'render'})`.

## Cross-session state

- `TASK_BOARD.md` — shared claims, written only by the orchestrator. Check it
  before a dispatch. It is awareness, not a lock.
- `TODO.md` — deferred goals, operator-owned. `harness.py todo --pick` returns the
  top `Ready: yes` row; `--id T2` returns that row.

A new workspace copies `templates/TASK_BOARD.md` and `templates/TODO.md` into
`design/` when the first claim starts. The live files are project-owned.

## Rules

- One fact has one home. Edit by delta. Never copy a template over a record.
- The frozen zone is the `## Interface <module>` sections in `architecture.md`
  and the accepted contracts in `modules/<m>.md` / `SKELETON.md`.
- A change to the module cut, an `Owns` set, or a frozen interface is `module-cut`.
- A subsystem with only `GOAL.md` is PLANNED, not started.
- Counts come from `model.json`. Contracts live once in the module file.

## Method

`protocol/design-procedure.md` is the step index. `protocol/design-protocol.md`
is the team contract. `reference/module-rules.md` is the freeze and parallel
split. `reference/design-craft-design.md` is the technique.
