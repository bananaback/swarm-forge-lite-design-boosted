# Install the harness

This folder is a complete, self-contained agent harness. Drop it at the root of a
workspace, install the dependencies, wire it to the project, and run it. It ships
**unwired**: it names no project and resolves no project path until you wire it.

## 1. Prerequisites

| Need | Required by | Notes |
| --- | --- | --- |
| `python3` 3.10+ | every `swarm-forge-lite/tools/` entry point | Modern annotations and typing throughout. |
| `pytest` | `harness_tests/`, `project_tests/` | Test runner for both persistent roots. |
| `hypothesis` | `harness_tests/persistent/property/` | Property tests. |
| `tree-sitter-language-pack` | `tools/shared/dryer/` | Pulls in `tree-sitter`. DRY scanning. |
| `PyYAML` | `switch_agent_model.py` | Agent frontmatter read/write. |
| `coverage` | `tools/refactorer/crapper/` | Python CRAP scoring reads an LCOV report. Absent, Python scores 0%. |
| `ruff` | `tools/shared/ruff4py/` | Found on `PATH` by name. |
| `bb` (Babashka) | `tools/shared/aps/` | `gherkin-parser`, `ir-dry-checker`, `gherkin-mutator`. Checks skip cleanly without it. |
| `node` | the umlview render tests | `test_umlview_layout.py`, `test_umlview_select.py` skip without it. |
| `codegraph` | the `codegraph` MCP server in `opencode.json` | `codegraph serve --mcp`. Optional; remove the server to skip it. |

```bash
python3 -m pip install pytest hypothesis tree-sitter-language-pack PyYAML coverage ruff
```

Missing a tool degrades that one check. Missing `python3` stops everything.

## 2. Install

1. **Place the folder at the workspace root.** The root is the directory OpenCode
   opens. It must contain `opencode.json`, `AGENTS.md`, and `swarm-forge-lite/`
   side by side.
2. **Install the prerequisites** (section 1).
3. **Optional - pick the agent models.** `opencode.json` sets the default model.
   To set a model per role, edit the `AGENT_MODELS` map in `switch_agent_model.py`
   and run it from the root:

   ```bash
   python3 switch_agent_model.py --list     # show the plan, write nothing
   python3 switch_agent_model.py            # apply it
   ```
4. **Wire the harness to the project.** The pack ships unwired: `swarm-forge-lite/harness.json`
   carries the placeholder `<PROJECT_ROOT>`. Follow `swarm-forge-lite/WIRING.md`.
   For a quick look before wiring, export the variable instead of editing:

   ```bash
   SWARM_PROJECT=/path/to/project python3 swarm-forge-lite/tools/shared/harness.py status
   ```
5. **Verify.** Every row must be `[ok]`, and no placeholder may remain:

   ```bash
   grep -c '<PROJECT_ROOT>' swarm-forge-lite/harness.json   # must print 0
   python3 swarm-forge-lite/tools/shared/harness.py status
   ```
6. **Run.** `AGENTS.md` and `opencode.json` are what OpenCode loads; the orchestrator
   agent drives the pipeline from there.

## 3. What is here

| Path | What it is |
| --- | --- |
| `.opencode/` | Agent, command, and plugin definitions: `agents/`, `commands/`, `plugins/`. |
| `AGENTS.md` | Agent instructions, loaded by `opencode.json`. |
| `opencode.json` | OpenCode config: default model, provider variants, permissions, MCP servers. |
| `switch_agent_model.py` | Assigns a model to each agent in `.opencode/agents/` from one map. |
| `swarm-forge-lite/` | The harness pack: `constitution/`, `protocol/`, `reference/`, `tools/`, `design/templates/`, `harness_tests/`, `project_tests/`. |

## 4. Per project - not part of this harness

- **Skills** live in `.agents/skills/`, with `skills-lock.json` recording them.
  Install the skills a project needs into that project. They are not carried here.
- **`.codegraph/`** is generated by the codegraph plugin. Do not copy an index;
  run `codegraph init` in the new workspace.

## 5. Entry points

- `python3 swarm-forge-lite/tools/shared/harness.py --help` - config, status, clean, records, envelopes.
- `swarm-forge-lite/tools/shared/lane <lane> <command>` - runs one command with every disposable output scoped to the lane.
- `swarm-forge-lite/WIRING.md` - the wiring runbook.
- `swarm-forge-lite/PROJECT.md` - the project facts template: fill `ENV`, `CONVENTIONS`, and `REFERENCES` per project.
